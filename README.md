# MPA-MLR · Machine Learning

Course materials of **MPA-MLR** (Department of Biomedical Engineering, FEEC,
Brno University of Technology), winter semester 2026/27.

**Course web:** https://tomasvicar.github.io/MLR-public/

This repository holds what the labs need: the student notebooks
(`exercises/exNN/exNN_student.ipynb`, opened in Google Colab from the course
web), the starter projects of the agent labs (`exercises/exNN/starter/`) and the
small datasets (`exercises/data/`). Materials are added as the semester
progresses — published so far: lectures 1,
exercises 1.
