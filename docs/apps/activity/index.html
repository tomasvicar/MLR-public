Activity timeline

Reads the phone's accelerometer in the browser, labels every sample with your ONNX model (lab 9) and draws a colour-coded timeline. Runs entirely on your device, nothing is uploaded.

Classes and preprocessing

Read from the model file (model_info); you may edit them and press Apply.

How to export your model 
import json, onnx, torch
model.eval().cpu()
torch.onnx.export(model, (torch.zeros(1, 3, 256),), "activity_model.onnx",
                  input_names=["acc"], output_names=["logits"],
                  external_data=False)
info = {"classes": ["walking", "upstairs", "downstairs", "sitting",
                    "standing", "lying", "transition"],
        "units": "g",          # what the network was trained on
        "sample_rate": 50,     # Hz
        "window": 256,         # samples, the length exported above
        "axes": ["x", "y", "z"]}
m = onnx.load("activity_model.onnx")
m.metadata_props.add(key="model_info", value=json.dumps(info))
onnx.save(m, "activity_model.onnx")

The network takes 1 × 3 × window and returns 1 × classes × window logits (one class per sample). Copy the file to your phone (e.g. through Google Drive or iCloud Drive) and choose it above.
