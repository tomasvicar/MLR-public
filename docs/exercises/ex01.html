Exercise 1 — Introduction, libraries, nearest neighbour

The tools of the course, a dataset we measure ourselves, and the simplest classifier there is

Week 1 · builds on the first lecture

▶ Open the notebook in Google Colab

What you will learn

  • What the four libraries of this course are for: NumPy (arrays), Matplotlib (plots), pandas (tables), scikit-learn (models).
  • How a real dataset is created — by measuring, writing down and cleaning up, not by downloading.
  • How a nearest-neighbour classifier decides: on paper, in a spreadsheet, and in NumPy — and that all three give the same numbers.
  • Why we write the code ourselves in the first labs, with the AI assistance switched off.

Before the lab

  • Recall from the first lecture how the Euclidean distance between two points is computed, and the 1-NN rule — find the closest training sample, predict its class.
  • If Python is new to you, watch the crash course below before the lab; we will not teach the language itself.
  • In Colab, switch off the AI features: Tools → Settings → AI Assistance, uncheck everything.

Tasks

A quick tour of NumPy, Matplotlib, pandas and scikit-learn comes first, with two small exercises to try. Then:

  1. Measure your leaves — measure the height and the width of three leaves and enter them into the shared spreadsheet; this is the dataset used today and in the next lab. Look at the table before trusting it and clean up what the class mistyped.
  2. Nearest neighbour by hand — six known leaves, one new leaf: compute the six distances on paper, first from the height alone, then from the height and the width; then the same six with one formula in a spreadsheet.
  3. The same six leaves in NumPy — write euk_dist, loop over the six leaves, use np.argmin, and check that the numbers match the blackboard.
  4. The whole dataset — repeat it with all the measured leaves and classify two new ones.

At the end, a first look at classes and methods — the preview of next week’s lab.

Data

  • Shared spreadsheet of the leaves — the dataset of this course, measured by you. Columns: Leaf height (cm), Leaf width (cm), Tree type (maple, cherry or walnut). It starts with three example rows, one per tree type; every student adds three more.
  • leaves_small.csv — the seven leaves of the by-hand task (download); the column Role says which six are the training set and which one is the new leaf.
  • leaf_measurement.png, leaf_measurement_height.png — how a leaf is measured: the height alone, and the height and the width as the sides of the smallest box containing the blade; in centimetres with one decimal place.
